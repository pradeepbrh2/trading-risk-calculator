Contact and feedback

Found a calculation issue, have an idea for a new tool, or want to suggest an improvement? Feedback helps prioritise the roadmap.

Report a bug or request a feature

Open the project's GitHub Issues page to describe the issue or suggestion.

Please do not include broker passwords, account numbers, personal financial statements or other sensitive information in a public issue.

What to include

  • Which page and feature you were using.
  • Steps needed to reproduce the issue.
  • Expected behaviour versus what happened.
  • Your browser and device, if relevant.
